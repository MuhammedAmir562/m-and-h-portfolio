# 🌟 Complete Beginner's Guide to Your Website (For Non-Coders!)

Welcome! If you have **never coded, never built a website, or never used AI before**, this guide explains **everything in plain, simple English**.

---

## 🧩 1. How a Website Works (The 3 Building Blocks)

Think of your website like a human body:

1. **HTML (`index.html`) — The Skeleton 🦴**
   - This holds all the content: headings, text, pictures, buttons, and forms.
2. **CSS (`css/styles.css`) — The Outfit & Style 👗**
   - This makes everything look gorgeous: dark mode colors, fonts, glow effects, rounded corners, and spacing.
3. **JavaScript (`js/app.js` & `js/data.js`) — The Brain & Memory 🧠**
   - This makes things interactive! When you click a button, search for an article, or open a story popup, JavaScript does the heavy lifting.

## ✏️ 4. How to Change Things (No Coding Experience Needed!)

### Want to edit an article or add new stories?
1. Open the file `js/data.js`.
2. Look for `blogPosts = [ ... ]`.
3. Change the text inside the quotes `"..."` (e.g., change `title: "My New Story"`).
4. Save the file!

### Want to change the colors or layout?
Simply tell the AI agent in natural words:
> *"Make the hero background a dark blue gradient and change the button text to Explore Now."*

The AI will handle all the technical details for you!
